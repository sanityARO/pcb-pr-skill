# 从原理图到通道布局

**同步前**从原理图列出每个关键接口的源、负载、串联器件、测试接点和参考电源/地。检查分压、上拉、参考输入和隔离电阻：同一网络名跨过隔离电阻时，拆电阻也无法隔离。自定义封装按打线图或封装图指定的观察面验算角脚、递增方向和至少一个非对称引脚；翻到背面后用板顶透视和实际装配面分别检查。

**布局底图**标出装配投影、上下表面的插拔/探测方向、镜头或散热器包络、探头及地弹簧可达区、通孔占据的全部铜层。在这些约束上布局。去耦同时靠近电源和回流引脚；四端分流器分开电流端和取样端；高阻模拟节点旁侧地是否有益要结合寄生电容评估。高速优先完整参考平面，增加护地铜前确认有连续的接地路径和合适间距。

**成组扇出实例**：两排固定连接器之间夹着一排隔离电阻，另一端还连一排调试针。先把三者的脚序投影到同一观察面，按目标侧引脚顺序给电阻分组、错开焊盘逃逸口；为贯穿总线留连续通道，把调试支路安排在主路外侧。依据可用横截面核算 n 条线的最少宽度 nW+(n−1)S，再加入两侧退让、过孔焊盘及其对相邻参考层的避空。估算通过后先试两端最难逃逸的线和整组入口。一次只移动一个候选组，保留电阻与原理图脚号的对应关系。

**按板分配优先级**：先确定电源铜和返回平面、关键器件扇出与屏障，再完成时钟、差分对、参考和敏感模拟线、有截止时序的数字组，最后补普通控制线与测点。电源预留应发生在普通信号占据瓶颈之前。差分换层同时安排 P/N 信号孔及贯通前后参考面的回流孔；检查主链路与调试支线各自长度、支线残桩和参考地。模拟地护线、高速线侧地和密集缝合孔均占空间，按阻抗截面、回流和负载需求决定。

## 外部布线往返

1. 在独立目录冻结原生板源、放置焊盘表、规则、DSN、路由器版本与参数。用上游 `scripts/routing` 的 README 和本机各命令的 `--help` 确认输入格式。已验证过的组合为 pcb-skill 提交 `6e939b64907e3c63236c7522c511af5d7d1afaad` 和 FreeRouting 2.5.0 JAR。其他版本从小网往返开始。
2. DSN 导出后用不共线的焊盘、背面非对称焊盘和一个通孔校准单位、坐标原点、镜像、转角及层表。核对光学开窗、线禁区、过孔禁区、已保护铜及孔阵列。分别处理“禁止走线”和“禁止通孔”；若导出器把实际孔写成重复的合成引脚，只在试布输入内消除重复表达。
3. 先选包含两层及一个调试支路的小网。按工程层叠改写 DSN 规则，锁定已接受铜，按需用 dsn_rewrite / dsn_slim 限制网络和层。运行选定路由器，保存 SES、命令、日志及退出状态；ses_import 解析后按几何与层别提取新增铜及明确授权的拆铜。对受保护的线比较几何覆盖，原生 API 有时会合并共线线段。
4. 在副本预检跨网间距、普通/差分线宽、孔径、板框、禁布、完整焊盘组和返回通道。小网连接核对后再扩大批次。提交后读回真实焊盘连通块：一条线出现两个焊盘已连而第三个 TP 未连，仍是断网。基线未含实铜时把依赖平面的网标为待重建。

## 候选取舍

对相同端点集合记录：各网含焊盘的连通块、断点总数（每网块数减一，最低为零）、同组已连的线长、过孔数、最窄电源颈部、参考面中断和最近有效回流孔。另列不同候选新接通的网络。总线长随接通数量增长，不能据此判它退步。

| 观测 | 下一次局部试验 | 接受条件 |
|---|---|---|
| 多根线在同一排焊盘前反复换层、折返 | 拆开挡住入口的普通线，在副本放宽电阻间距、调整朝向，整组重新扇出 | 同一组通过瓶颈；原被绕开的网恢复；同一端点集的绕行或换层确有改善 |
| 差分对支路换层挖断主线参考地 | 联动移动信号孔和地孔，优先维持主线；可移动的邻线局部让位 | 证实该地孔连接两个参考面；分别比较主线、支路的连续缺口及相对长度 |
| 密集封装的少数引脚无出口 | 普通通孔、邻线首段微调、局部重放阻容各作候选，再评估盘中孔 | 留存的盘中孔逐孔列出引脚、网络、坐标、孔径、焊盘边距、制造工艺；删去并未承担换层的孔 |
| 回退会破坏固定件、减少供电铜或引入新的短路 | 放弃这个候选，返回上次通过的源文件；试另一侧或另一组 | 固定项、网表和已验收关键路径均可验证；无法满足时标出具体冲突供设计方决定 |

普通线是否借用电源层，按局部铜颈、电源分流、穿越信号参考及替代方案评估。只有评估结果允许时才用该层。最后按实际插接状态检查测点、丝印、插拔及返修空间。
