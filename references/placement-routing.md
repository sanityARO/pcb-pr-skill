# 从板级原理图到通道布局

## 设计时使用规则

先读取与当前任务有关的板级原理图、器件要求、制造条件及固定项，建立精简的项目约束。每个关键网络或网络组记录源与负载、功能/电源域、边沿或工作频带、层与参考面、线宽/间距依据、测试接法及待确认项。已有可靠规则可以复用。

**默认建议**提供可调整的布局起点。**必须检查**在相应场景出现时触发，要求根据器件、接口、误差预算或制造能力判断当前方案。不存在该场景可略过，有依据的例外记录原因和验证方法。输入不足时限定结论与受影响操作，并继续独立工作。下列检查随设计推进使用，阶段完成后再对最终几何复验。

**约束优先级。** 功能与电气安全、器件极限和已确认制造限制优先，随后满足接口、阻抗、载流、压降和噪声预算，最后采用项目默认值及美观偏好。冲突时调整相关结构并记录依据，保留其它网络的约束。

### 同步和布局时

| 决策时机 | 默认建议 | 必须检查及其适用条件 |
|---|---|---|
| 同步板级原理图与选择库件 | 复用有版本证据的库件，先明确电源与接口状态。 | 器件、封装或映射变化时对照具体料号、原厂图和实际焊盘。自定义器件按指定观察面核对角脚、递增方向和非对称引脚，背面同时检查板顶透视及装配面。工具报差异时追踪实例编号、跨页标志、允许短接及焊盘网络。 |
| 分类与安排接口 | 按源阻抗、边沿、频带和误差预算分类，预留有用途的隔离/选源位置。 | 复位、片选、使能在未配置及支持的掉电状态下有确定行为。跨域或外部注入时检查电平、钳位、Ioff 条件及反灌；串阻与上下拉组合需核算分压、RC 与逻辑裕量。SPI 的极性、方向和时序从器件时序图及接口设计说明读取。 |
| 选层和机械布局 | 先安排机械接口、电流去回路径、敏感节点及快速信号通道，再填普通控制线；固定件按已确认阶段管理。 | 使用真实板厂叠层，为信号指出有效参考层。检查板边、槽、螺钉/垫圈、工具和连接器包络。固定项改动须有差异记录。所需层数和层分配依据参考平面、供电及可布性决定。 |
| 放置阻容和去耦 | 无操作需求的器件可背装以释放通道，关键去耦围绕电源脚与返回脚布置。 | 按每个电源脚需求检查实际去耦回路和局部储能。电容有效容量与耐压按偏压、温度、容差和瞬态评估；采用 LDO、磁珠或精密基准时核对负载、稳定性、损耗、噪声及谐振。换背面后重新考虑过孔环路、装配高度和返修空间。 |
| 安排测量接点 | 按测试项目选择可达的 TP、排针、同轴或缓冲支路，并就近提供适合探头的参考地。 | 隔离电阻两端须能真正断开，外部选源互斥且默认装配明确。高阻/宽带节点检查焊盘与探头 R/C 负载。同轴接口明确方向、幅度标定、终端和容许输入。电流测量明确采样边界、Kelvin 接点、共模、带宽及仪器接地，计入取样后储能影响。整体仪器带宽预算参照测量方案。 |

在布局底图标出装配投影、插拔/探测方向、镜头或散热器包络、探头地弹簧可达区和通孔占据的全部铜层。根据这些空间预算安排器件。四端分流器分开电流与取样端，保护接地仪器的地夹接法需符合采样共模条件。

### 每组布线时

| 决策时机 | 默认建议 | 必须检查及其适用条件 |
|---|---|---|
| 确定线宽和供电通道 | 先预留电源铜与返回路径，再安排关键扇出、时钟/差分/敏感模拟组，最后填普通控制线。 | 电源从端子、触点、滤波、分流器、铜颈、热焊辐条、过孔到负载及地回流，均按工作电流、压降、温升和瞬态条件评估。细脚短出线也计入瓶颈，不能用铜皮总面积或固定“每孔电流”替代。 |
| 起走快速信号或差分对 | 快速性依据边沿与互连延时判断。差分优先同层、同参考、对称，端接靠器件要求的位置安排。 | 受控阻抗按实际叠层、铜厚、阻焊、邻近铜及接口目标设宽度/间距，并核对规则绑定。检查端接、对内时序裕量、主线及调试支路；测试支路不计作点对点主线长度。普通 CMOS 是否需受控阻抗或串联阻尼由链路决定。 |
| 通过空洞、换层或接入支路 | 保持连续参考面；信号换层时一起选信号孔与邻近返回结构。 | 逐段追踪有效参考面。前后均参考 GND 时核对回流孔实际接通两面；不同参考域需设计适合的返回结构。避免把跨槽或平面缺口留到走完后处理。新增支路评估残桩、探头负载及孔避空对主线的影响。 |
| 平行走线与加侧地 | 优先缩短平行段、增加间隔并贴近参考面。侧地、守卫和缝合孔按需求安排。 | 加侧地时核对接地连通、细颈、孤岛和阻抗截面；差分内部的铜会改变耦合。高阻模拟节点评估漏电、清洁、湿度和输入电容，需要时使用稳定的驱动守卫。接地屏蔽与驱动守卫分别设计。 |
| 逃逸焊盘或增加过孔 | 优先常规通孔，能扩宽的短细颈及时扩宽。 | 按工厂能力检查孔/盘、环宽、孔间距、孔到铜及阻焊。盘中孔依据装配和制造工艺专门确认。阻抗过渡与高电流细颈按相应预算处理，避免自动把整网放宽为最细逃逸规则。 |

### 可选的低压测试板预设

仅在项目选择该预设后应用，适合空间允许的低压刚性实验板。高压隔离、射频天线、柔性板或高密度封装另按实际需求设置。以下数值是试算/布局起点，制造与电气约束可覆盖它们。

| 参数 | 可选起点 | 采用前判断 |
|---|---|---|
| 普通非阻抗信号 / 供电干线 | ≥10 / ≥20 mil（≥0.254 / ≥0.508 mm） | 作为所选预设的起始下限。电源按电流、铜厚、长度、压降与温升加宽或铺铜，电压和瞬态同时决定净距、绝缘与器件额定值；细脚、受控阻抗、高阻节点单独确定并记录例外。 |
| 短细颈扩宽 / 邻近回流孔 | 约 1 mm 内 | 依据间距、细颈能力、阻抗过渡和实际回流调整；距离本身不能证明通过。 |
| 普通常规通孔孔/盘 | 0.30 / 0.60 mm | 核对环宽、板厚纵横比、孔壁铜厚、载流及工厂能力。 |
| 铣边/槽铜净距 | 0.30 mm | 按厂家公差、电压和局部结构决定最终值。 |
| 小型数字 IC 局部去耦 | 100 nF，靠近电源脚约 1–2 mm | 器件要求、有效容量和整个回路决定数量及位置。 |
| 普通逻辑上下拉 / CMOS 串联阻尼 | 10 kΩ / 22–47 Ω | 验证逻辑裕量、驱动阻抗、边沿与负载；源端串联阻尼靠近驱动端安排。 |

3W 等间距口诀仅用于初步排布，先明确边距或中心距，再结合参考高度、平行长度及边沿评估串扰。四层 S/GND/GND/S 可作为外层信号及电源布线的候选，按实际电源需求与回流选择其它方案。

## 布局审查与继续布线

布局完成后保存板源、网表与约束检查点，提交布局图、关键器件位姿、供电与回流通道、探测/插拔空间及待确认项给真人审查。记录审查的版本、同意的范围和修改要求。审查通过且已同意布线后再开始走线；可以保存检查点，之后恢复。已有批准且约束未变的版本可直接续接，避免重复索要确认。

布线中按已授权范围局部优化。若重排影响已批准的固定项、功能分区、机械或回流通道，先提交受影响布局复审，再继续相关布线。其它不依赖该调整的工作可继续。比较候选时保留原布局及被移动器件的差异。

## 成组扇出与通道预算

两排固定连接器之间夹着一排隔离电阻，另一端还连一排调试针时，先把三者的脚序投影到同一观察面，按目标侧引脚顺序给电阻分组、错开焊盘逃逸口。为贯穿总线留连续通道，把调试支路安排在主路外侧。依据可用横截面核算 n 条线的最少宽度 nW+(n−1)S，再加入两侧退让、过孔焊盘及其对相邻参考层的避空。估算通过后先试两端最难逃逸的线和整组入口。一次只移动一个候选组，保留电阻与板级原理图脚号的对应关系。布局阶段在人工确认后试布；后续重排遵循上述复审范围。

## 外部布线往返

从已获准布线的检查点开始。PcbCliTool 路径按其版本文档验证本地读取、规则、导出和写回；下面的 DSN/SES 方法适用于选用 pcb-skill 外部路由器的任务。使用 easyeda-api 时，按现场文档核对客户端身份。选择任一路径都要保存冻结版及明确的写入目标。

1. 在独立目录冻结原生板源、放置焊盘表、规则、DSN、路由器版本与参数。用上游 `scripts/routing` 的 README 和本机各命令的 `--help` 确认输入格式。已验证过的组合为 pcb-skill 提交 `6e939b64907e3c63236c7522c511af5d7d1afaad` 和 FreeRouting 2.5.0 JAR。其他版本从小网往返开始。
2. DSN 导出后用不共线的焊盘、背面非对称焊盘和一个通孔校准单位、坐标原点、镜像、转角及层表。核对光学开窗、线禁区、过孔禁区、已保护铜及孔阵列。分别处理“禁止走线”和“禁止通孔”；若导出器把实际孔写成重复的合成引脚，只在试布输入内消除重复表达。
3. 先选包含两层及一个调试支路的小网。按工程层叠改写 DSN 规则，锁定已接受铜，按需用 dsn_rewrite / dsn_slim 限制网络和层。运行选定路由器，保存 SES、命令、日志及退出状态；ses_import 解析后按几何与层别提取新增铜及明确授权的拆铜。对受保护的线比较几何覆盖，原生 API 有时会合并共线线段。
4. 在副本预检跨网间距、普通/差分线宽、孔径、板框、禁布、完整焊盘组和返回通道。小网连接核对后再扩大批次。提交后读回真实焊盘连通块：一条线出现两个焊盘已连而第三个 TP 未连，仍是断网。基线未含实铜时把依赖平面的网标为待重建。

## 候选取舍

对相同端点集合记录：各网含焊盘的连通块、断点总数（每网块数减一，最低为零）、同组已连的线长、过孔数、最窄电源颈部、参考面中断和最近有效回流孔。另列不同候选新接通的网络。总线长随接通数量增长，不能据此判它退步。

| 观测 | 下一次局部试验 | 接受条件 |
|---|---|---|
| 多根线在同一排焊盘前反复换层、折返 | 拆开挡住入口的普通线，在副本放宽电阻间距、调整朝向，整组重新扇出 | 同一组通过瓶颈；原被绕开的网恢复；同一端点集的绕行或换层确有改善 |
| 差分对支路换层挖断主线参考地 | 联动移动信号孔和地孔，优先维持主线；可移动的邻线局部让位 | 证实该地孔连接两个参考面；分别比较主线、支路的连续缺口及相对长度 |
| 密集封装的少数引脚无出口 | 普通通孔、邻线首段微调、局部重放阻容各作候选，再评估盘中孔 | 留存的盘中孔逐孔列出引脚、网络、坐标、孔径、焊盘边距、制造工艺；删去并未承担换层的孔 |
| 回退会破坏固定件、减少供电铜或引入新的短路 | 放弃这个候选，返回上次通过的源文件；试另一侧或另一组 | 固定项、网表和已验收关键路径均可验证；无法满足时标出具体冲突供设计方决定 |

普通线是否借用电源层，按局部铜颈、电源分流、穿越信号参考及替代方案评估。只有评估结果允许时才用该层。最后按实际插接状态检查测点、丝印、插拔及返修空间。
