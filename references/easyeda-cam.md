# 现场执行与实铜验收

## 先辨认文档，再运行命令

准备 Node 18+ 和 easyeda-api 网关。按该技能的文档发现本机端口，查 `/health`、`/eda-windows` 和 `eda.dmt_Project.getCurrentProjectInfo()`；从工程树取得目标板 UUID，切至该板。多个窗口时用环境变量 `EASYEDA_WINDOW_ID` 指定目标；端口可用 `EASYEDA_BRIDGE_PORT` 覆盖。下列命令从本技能目录运行，将 PROJECT、BOARD 和输出文件替换为实际值。每个输出路径须为新文件，父目录须存在。

```text
node scripts/board-job.mjs snapshot PROJECT BOARD before.epcb
node scripts/board-job.mjs pour-save PROJECT BOARD pour-receipt.json
node scripts/board-job.mjs drc PROJECT BOARD drc.json
node scripts/board-job.mjs gerber PROJECT BOARD check.zip
```

`snapshot` 适用于已放置器件的板。`pour-save` 是上述命令中唯一会修改并保存板图的命令，仅在用户要求的板与阶段使用；需已有铺铜边界。它枚举铺铜对象，逐个执行 `rebuildCopperRegion()`，记录成功对象并保存。此顺序在 easyeda-api 1.1.36、嘉立创EDA 4.1.99 的桌面工程验证过。关闭、重开并读回填充几何可验证持久性。判断“实铜一致”时按区域比对轮廓、内孔、层别，容许有记录的序列重排和远小于制造精度的浮点差。

长任务在扩展内运行一次，客户端脚本轮询同一作业编号。超时后用原命令追加打印出的 JOB_UUID 查询。扩展重新加载可能使内存状态失效；此时先读回现场再判断是否要继续。逐区重建中途失败可能已更新部分区域。仅看到进度结束、API 返回空值或出现大面积颜色，都不能确定结果已保存。返回 DRC 空数组表示本次详细检查无报告项；非空时保留原始返回并检查分类、叶项和豁免情况。

何时请用户操作：当前客户端缺少逐区接口、网关无法确认活动板、或 SDK 导出的铜层与客户端显示显著不一致时。优先尝试读回、检查已有作业与区域填充；必要时请用户在铺铜管理器重建或从同一板导出一次诊断包。保存状态有疑问时重开核验。可临时隐藏或在副本移除阻挡试布的面铜；保留边界、网络、优先级、净距、禁止区和层定义。依赖平面的连接在此期间单列。信号阶段结束后统一恢复和重建。

## 从制造文件复核

获取独立的、与这版板一致的带网焊盘表，逐项核对器件位姿、焊盘 ID、脚号、网络、所在层和坐标。Gerber ZIP、钻孔和该表必须使用同一原点和方向。脚号可重复（例如连接器的多个屏蔽脚）；给每个物理焊盘一个唯一 ID。预期网络列表取自板端已分配到物理焊盘的网络集合，缺少网名应报错。独立列出设计允许相连的 net-tie，当前脚本会将其报告为异网共铜；由设计方按位置核实。

以下为 manifest 的字段示例。真实板必须列全铜层、所有贯通镀孔文件、所有预期网络及所有带网器件焊盘。`layers` 在焊盘条目内表示**明确要求有该焊盘铜的层**，插件孔可按设计列顶底层，不把无焊盘的内层也当作缺铜。圆形 PTH 的层间连接由钻孔文件另行建立。

```json
{
  "bounds_mm": [0, 0, 40, 30],
  "layers": ["top.GTL", "bottom.GBL"],
  "plated_through": ["vias.DRL", "pins.DRL"],
  "nets": ["CLOCK"],
  "pads": [
    {"id": "U1.2", "net": "CLOCK", "xy_mm": [8,10], "layers": ["top.GTL"]},
    {"id": "J1.1", "net": "CLOCK", "xy_mm": [25,10], "layers": ["top.GTL","bottom.GBL"]}
  ]
}
```

使用单独的 Python 环境，安装 numpy、scipy，并提供 pcb-skill 源代码目录。执行前核对 ZIP 中的层和钻孔清单，特别是独立的插件孔、过孔和非金属化孔。通孔表包括全部电气 PTH，排除 NPTH。

```text
python scripts/cam-check.py check.zip manifest.json connectivity.json --pcb-skill PATH_TO_PCB_SKILL --resolution 0.025
python scripts/test-cam.py PATH_TO_PCB_SKILL
```

第二条命令生成临时双层样板，分别检查正常连接、少一个镀孔造成的开路、以及两网意外共铜。Excellon 使用绝对坐标和显式毫米小数；隐含小数格式先由可靠的 CAM 工具转换，再核对钻孔原点与层图叠合。

脚本逐层栅格化实际铜形，标记相接区域，经金属化孔合并各层，再将独立的焊盘网络标签映射到铜。每个预期网应有一个连通体；异网共用的连通体、落不到铜的焊盘均报告。退出码 0 为通过，1 为连通检查失败；解析或输入错误也会非零退出。0.025 mm 是一个验证过的示例分辨率。按最小铜间隙、窄颈及焊盘尺寸选网格，对临界结果用更细网格或矢量 CAM 复核。代码继承上游解析器的格式限制，仅适用于其支持的正铜、圆形贯通镀孔和有铜的焊盘中心采样点；负片、盲埋孔、长槽镀孔、偏置采样点等另选支持这些特性的 CAM。该检查不能发现所有无网孤铜、钻偏或亚像素短路。

## 比较通过后仍要回答的三个问题

1. **回流在何处闭合？** 检查每段信号实际参考层，沿主线和调试支路分别投影至实铜；跨线段合并连续缺口。由信号孔量到同时接入两参考面的地孔。记录采样间隔、距离和最差位置。若参考层属于不同电源域，评估合适的跨参考返回结构。中心线覆盖与地孔距离是几何证据，阻抗、抖动和眼图需另行建模或实测。
2. **大电流从哪里进入和返回？** 逐一识别端子、磁珠、分流器电流端、各段铜颈、并联过孔、负载脚、去耦与回流。分开估计铜片直流电阻、焊盘与过孔电阻和瞬态环路电感。没有峰值脉宽、占空比或允许压降时，写明可证实的连通与几何，留下需测的电气条件。
3. **本次试布如何成为正式版？** 先备份正式板；用工程和文档身份锁定写入对象，保持目标文档与原理图的关联。保存、重开后核对器件和焊盘映射、几何、网络、规则、实际填充以及副本仍在。最后从正式板获取原生 DRC、Gerber、钻孔、SHA-256；制造说明注明实际叠层、阻抗、开窗、填孔与需板厂确认的公差。
